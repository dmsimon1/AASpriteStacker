Classic 2D slice stacking snaps pixels to a jagged grid, or bleeds dark halos as soon as you turn on bilinear filtering. AASpriteStacker raycasts the volume in linear light, keeping the pixel-art interior sharp without rotation aliasing. New to sprite stacking? Read the primer →

1. Stop Rotation Shimmer

Instead of snapping flat quads to pixel centers, AASpriteStacker raycasts a tight 3D volume with rotated-grid supersampling (RGSS) in linear light, cutting 1° rotation shimmer by 58%.

2. Keep 1px Details, No Dark Halos

Premultiplied linear blending, RGB edge dilation, and correlated coverage prevent transparent pixels from bleeding dark fringes while keeping thin posts, roofs, and outlines intact at every angle.

3. Live AA Quality Toggle (2.5D to 6-DOF)

Continuous 3D volume stepping stays solid at any camera pitch. Call setQuality("eco" | "balanced" | "ultra") at runtime to switch between lightweight 2×/4× sampling and full Retina 8× AA.

Add anti-aliased sprite stacking in 15 lines.

Zero runtime dependencies. Works directly in WebGL2, or convert standard 4-view art / MagicaVoxel .vox files.

import { AASpriteRenderer, SceneWorld, createIsometricCamera, loadSliceStripUrl, quatFromYawPitchRoll } from "@aastack/core";

// Layer over any existing 2D canvas/tilemap with premultiplied transparent alpha:
const renderer = new AASpriteRenderer(canvas, { background: "transparent", quality: "ultra" });
const world = new SceneWorld({
  // Presets: "dimetric-2to1" | "isometric" | "oblique-stack" | "topdown-3quarter"
  camera: createIsometricCamera({ preset: "dimetric-2to1", target: [0, 2, 0], orthoSize: 9.5 }),
});

// Load standard slices.png strips (or MagicaVoxel via loadVoxUrl("/model.vox", { id: "car" })):
const car = await loadSliceStripUrl("/car_slices.png", { id: "car", slices: 20 });
world.registerAsset(car);
world.applyPatch([
  { op: "set", path: "aaMode", value: "voxel-dda" }, // Crisp pixel-art interior + smooth AA edges
  { op: "spawn", entity: { id: "hero", assetId: "car", pos: [0, 2.8, 0], rot: quatFromYawPitchRoll(0.6, 0, 0), scale: 1, outline: true } },
]);

// Switch AA quality at runtime ("eco" 2x | "balanced" 4x | "ultra" 8x Retina + full-res outlines):
renderer.setQuality("ultra", world);
renderer.render(world);
