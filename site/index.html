Classic 2D slice stacking snaps pixels to a jagged grid—or bleeds black halos if you turn on bilinear filtering. AASpriteStacker raycasts the volume in linear light, keeping authentic pixel-art interiors sharp while eliminating rotation aliasing. New to sprite stacking? Read the 2-min primer →

1. Kill Rotation Shimmer

Instead of snapping flat quads to pixel centers, AASpriteStacker raycasts a tight 3D volume with rotated-grid supersampling (RGSS) in linear light—cutting 1° rotation shimmer by 58%.

2. Keep 1px Details, Zero Black Halos

Premultiplied linear blending, RGB edge dilation, and correlated coverage stop transparent pixels from bleeding dark fringes and keep thin posts, roofs, and outlines solid at every angle.

3. Live AA Quality Softswitch (2.5D → 6-DOF)

Continuous 3D volume stepping stays solid at any tilt, and a live setQuality("eco" | "balanced" | "ultra") softswitch lets developers and players dial between battery-cool 2×/4× and full Retina 8× AA on the fly.

Add anti-aliased sprite stacking in 15 lines.

Zero runtime dependencies. Works directly in WebGL2, or convert standard 4-view art / MagicaVoxel .vox files.

import { AASpriteRenderer, SceneWorld, createIsometricCamera, loadSliceStripUrl, quatFromYawPitchRoll } from "@aastack/core";

// Drop straight over any existing 2D canvas/tilemap with premultiplied transparent alpha:
const renderer = new AASpriteRenderer(canvas, { background: "transparent", quality: "ultra" });
const world = new SceneWorld({
  // First-class presets: "dimetric-2to1" | "isometric" | "oblique-stack" | "topdown-3quarter"
  camera: createIsometricCamera({ preset: "dimetric-2to1", target: [0, 2, 0], orthoSize: 9.5 }),
});

// Load standard slices.png strips (or MagicaVoxel via loadVoxUrl("/model.vox", { id: "car" })):
const car = await loadSliceStripUrl("/car_slices.png", { id: "car", slices: 24 });
world.registerAsset(car);
world.applyPatch([
  { op: "set", path: "aaMode", value: "voxel-dda" }, // Crisp pixel-art interior + smooth AA edges
  { op: "spawn", entity: { id: "hero", assetId: "car", pos: [0, 2.8, 0], rot: quatFromYawPitchRoll(0.6, 0, 0), scale: 1, outline: true } },
]);

// Runtime AA quality softswitch ("eco" 2x | "balanced" 4x | "ultra" 8x Retina + full-res outlines):
renderer.setQuality("ultra", world);
renderer.render(world);
# Clone the MIT open-source monorepo (zero runtime dependencies):
git clone https://github.com/dmsimon1/AASpriteStacker.git
cd AASpriteStacker
npm install && npm run build && npm run dev:serve
